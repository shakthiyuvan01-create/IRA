# Treasure Fire

A deploy-ready browser game prototype. It includes the Treasure Fire intro logo, lobby, friends and squad flow, training scenario, armory, Royale events, achievements, and graphics settings.

## Run locally

```powershell
npm install
npm start
```

Open `http://localhost:3000`.

## Deploy on Render

1. Create a new GitHub repository and push this folder.
2. In Render, choose **New → Web Service** and connect the repository.
3. Set Build Command to `npm install` and Start Command to `npm start`.
4. Deploy.

Render supplies `PORT` automatically.
